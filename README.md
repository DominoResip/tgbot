# СПТ · бот расписания (1 корпус)

Telegram-бот фактического расписания [Сибирского политехнического техникума](https://schedule.spt42.ru/1_korpus/hg.htm).

Работает в личке и в группах. Второй корпус можно подключить позже тем же кодом, сменив `SCHEDULE_BASE`.

## Что умеет

- Сегодня / завтра / неделя / текущая или следующая пара
- Все группы учащихся с сайта, плюс просмотр по преподавателям и аудиториям
- Настройки отображения: преподаватель, аудитория, время звонков, пустые пары, компактный вид
- Уведомления, когда на сайте меняется расписание выбранной группы / преподавателя / аудитории
- Опциональная утренняя рассылка пар
- Поиск: в личке напишите `АСУ-25`, `Чеботова` или `423`

Источник — «Экспресс-расписание» (страницы `hg.htm` / `hp.htm` / `ha.htm` и недельные `cg*.htm`).

## Хостинг

Бот может работать на VPS. Деплой с ПК (нужны `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_PASSWORD`):

```powershell
cd C:\!Programs\3\SptBot
.\.venv\Scripts\python.exe deploy_remote.py
```

Сервис: `systemctl status sptbot` на сервере. Каталог: `/opt/sptbot`.

## VPN / Happ

Telegram часто недоступен без VPN, а сайт техникума через VPN грузится очень медленно.

В Happ добавьте в **Direct / обход прокси**:
- `schedule.spt42.ru`
- `*.spt42.ru`

Тогда бот ходит в Telegram через VPN, а расписание — напрямую и быстрее.

Таймауты сайта: `FETCH_TIMEOUT=90`, повторы `FETCH_RETRIES=4` в `.env`.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather):
   - `/newbot`
   - `/setprivacy` → **Disable** (чтобы в группах работал поиск и кнопки)
   - Группы: включите добавление бота в группы
2. Скопируйте конфиг и вставьте токен:

```powershell
cd C:\!Programs\3\SptBot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
notepad .env
```

В `.env`:

```
TELEGRAM_BOT_TOKEN=123456789:token
ADMIN_IDS=ваш_telegram_id
```

3. Запуск:

```powershell
python bot.py
```

База SQLite появится в `data/sptbot.sqlite3`.

## Звонки

Время пар задано в `config.py` (`BELLS`). Если у 1 корпуса другой график — поправьте словарь. Показ звонков в сообщениях включается в /settings.

## Уведомления

Бот опрашивает сайт каждые `POLL_SECONDS` (по умолчанию 3 минуты). Если строка «Обновлено: …» или пары выбранной сущности изменились — подписчикам уходит новое расписание. Смена календарного дня сама по себе не считается правкой.

Утреннее сообщение — флаг «Утром прислать пары», время в `MORNING_HOUR` / `MORNING_MINUTE` (часовой пояс Кемерово `Asia/Novokuznetsk`).

## Группы Telegram

Добавьте бота в чат группы, админ выбирает учебную группу. Дальше `/today`, `/week` и кнопки под сообщением доступны всем. Менять группу и настройки могут только администраторы чата.

## Команды

| Команда | Назначение |
|---|---|
| `/start` | Приветствие и выбор |
| `/today` `/tomorrow` `/week` `/next` | Расписание |
| `/group` `/teacher` `/room` | Сменить объект |
| `/settings` | Вид + уведомления |
| `/notify` | Быстро вкл/выкл правки с сайта |
| `/refresh` | Принудительно скачать сайт (только `ADMIN_IDS`) |
